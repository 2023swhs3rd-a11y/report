# 진로 빌드업 맵 탐구 보고서 — 온라인 제출 도구

학생은 웹페이지에서 5단계(1차시 → 과제 1 → 2차시 → 과제 2 → 3차시)로 보고서를 저장하고, 내용은 선생님의 구글 시트에 쌓입니다. 선생님은 같은 페이지의 교사 화면에서 제출 현황, 확인·피드백, 평가 기준표, 특기사항 초안, 학생부 작성용 요약을 다룹니다.

## 바로 가기

- **학생용**: <https://2023swhs3rd-a11y.github.io/report/> (로그인 없이 '👀 둘러보기'도 가능)
- **선생님용**: <https://2023swhs3rd-a11y.github.io/report/#teacher> (교사 비밀번호 필요)
- 진로진학부 사이트 첫 화면: <https://2023swhs3rd-a11y.github.io/>

## 파일

| 파일 | 용도 |
| --- | --- |
| `index.html` | 페이지 뼈대와 보안 설정(CSP) |
| `js/config.js` | **저장 서버(Apps Script 웹 앱) 주소** 한 줄. 비우면 미리보기 모드 |
| `js/schema.js` | **보고서 구성**: 단계, 칸, 칸별 예시(`ex`), 추천 사이트(`LINKS`), 예시 친구(`PEOPLE`) |
| `js/samples.js` | 교사 화면 '📚 완성 예시'의 예시 학생 2명과 특기사항 예시 |
| `js/app.js` | 화면 동작(학생·둘러보기·교사·인쇄) |
| `css/app.css` | 모양 |
| `img/` | 탐구 지도 그림(`map.svg`), 완성 그림(`done.svg`), 파비콘(접힌 지도와 위치 핀: `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`) |
| `og.png` | 카톡·SNS로 주소를 보낼 때 뜨는 미리보기 이미지(1200×630). 원본은 `tools/og/og.html`, 다시 만들 때는 `node tools/render-og.js` 후 `index.html`의 `og.png?v=` 숫자를 올림 |
| `apps-script/Code.gs` | 구글 시트에 저장하는 스크립트. **비밀번호가 들어 있지 않아** 저장소에 두어도 안전 |
| `apps-script/Code.template.gs` | `Code.gs`의 원본(시트 열 목록만 비어 있음) |
| `tools/build-code-gs.js` | `js/schema.js`를 읽어 `Code.gs`의 시트 열 목록을 채움 |
| `tools/test-code-gs.js` | 가짜 시트 위에서 `Code.gs`를 시험 |

`js/config.js`의 주소를 비우면 **미리보기 모드**로 열립니다. 그 기기에만 저장되고, 교사 비밀번호는 `demo`입니다.

## 왜 HTML·JS로 만들었나요?

- GitHub Pages는 파일을 그대로 보내 주는 '정적' 호스팅이라 브라우저에서 돌아가는 HTML·CSS·JavaScript만 쓸 수 있습니다. 파이썬이나 PHP 같은 서버 언어는 돌릴 수 없습니다.
- 저장은 구글 Apps Script(구글 서버에서 도는 JavaScript)가 맡습니다. 그래서 별도 서버, 데이터베이스, 비용 없이 학교 구글 시트에 바로 쌓을 수 있습니다.
- React 같은 프레임워크는 '빌드' 단계가 필요해 고치기가 번거로워집니다. 지금 규모에서는 그대로 고칠 수 있는 파일이 낫다고 판단했습니다.
- 처음에는 올리기 쉽게 한 파일이었지만, 지금은 역할별로 나눴습니다. 나누면 보안 규칙(CSP)으로 페이지 밖 스크립트 실행을 막을 수 있고, 예시나 칸을 고칠 때 `js/schema.js`만 보면 됩니다.
- 빌드·시험 도구는 Node.js로 작성했습니다(`tools/`).

## 처음 설치 (약 15분)

### 1. 구글 시트와 스크립트

1. 구글 드라이브에서 새 스프레드시트를 만듭니다. **다른 사람과 공유하지 않습니다.**
2. **확장 프로그램 → Apps Script**를 열고, 기본 코드를 지운 뒤 `apps-script/Code.gs` 내용 전체를 붙여 넣고 저장합니다.
3. 왼쪽 **톱니바퀴(프로젝트 설정) → 스크립트 속성 → 스크립트 속성 추가**
   - 속성: `TEACHER_PASSWORD`
   - 값: 10자 이상의 교사 비밀번호
   - (권장) 속성 `TEACHER_PASSWORD2`, 값: 다른 10자 이상의 보조 비밀번호. 누가 교사 비밀번호를 일부러 틀려 교사 화면이 10분 동안 막혀도 이것으로는 들어올 수 있습니다.
4. 함수 목록에서 `setup`을 고르고 **실행** → 권한 승인. 시트에 `보고서`, `명단`이 생깁니다.

### 2. 웹 앱으로 배포

1. **배포 → 새 배포 → 유형: 웹 앱**, 실행 계정 **나**, 액세스 권한 **모든 사용자**.
2. 나온 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 `js/config.js`의 따옴표 안에 넣습니다.
3. 학교 계정에서 '모든 사용자'가 보이지 않으면 관리자가 외부 공개를 막아 둔 것입니다.

### 3. 웹페이지

저장소 **Settings → Pages → Deploy from a branch → main / (root)**. 1~2분 뒤 위 주소가 열립니다.

## 스크립트를 바꿨을 때 (재배포)

1. `apps-script/Code.gs` 전체를 Apps Script 편집기에 다시 붙여 넣고 저장합니다.
2. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**. 주소는 그대로입니다.
3. 교사 비밀번호를 스크립트 속성으로 옮긴 버전부터는 `TEACHER_PASSWORD` 속성이 꼭 있어야 교사 화면이 열립니다.

## 단계와 수준별 구조

| 단계 | 이름 | 구분 |
| --- | --- | --- |
| 💡 1차시 | 질문 찾기 | 🏫 수업 |
| 📚 과제 1 | 자료 탐험 | 🏠 과제 |
| 🧩 2차시 | 답 정리 | 🏫 수업 |
| ✍️ 과제 2 | 글 완성 | 🏠 과제 |
| 🎤 3차시 | 발표·성찰 | 🏫 수업 |

- **🌱 이것만 하면 완성**: 단계마다 필수 칸 목록이 위에 나오고, 쓰는 대로 ✓가 표시됩니다. 학습 의욕이 낮은 학생도 어디까지 하면 끝인지 바로 알 수 있습니다.
- **막힐 때 돕는 장치**: 칸마다 펼쳐진 두 친구의 예시, 문장 틀, 관심 단어 고르기 버튼, 질문 틀 넣기 버튼(고른 단어와 조사를 맞춰 넣음)이 있습니다.
- **🚀 더 해 보고 싶다면**: 단계마다 도전 과제를 두 개씩 제시합니다. 도전 칸 두 개(⑧ 다른 의견·한계, 다음 탐구 계획)는 필수가 아니어서 쓰지 않아도 완성으로 칩니다.
- **🔗 이전 활동과 이어 보기(1차시)**: 어떤 활동과 이어지는지(교과 수업·수행평가, 진로 특강, 동아리, 독서 등 버튼), 그 활동에서 한 일, 그때 남은 궁금증과 이번 탐구가 이어지는 점, 다른 과목 개념과의 연결을 씁니다. 필수는 아니지만 관심의 흐름과 교과 연계가 학생부에 드러나도록 강력 추천으로 표시했고, 학생부 작성용 요약과 완성 예시 특기사항에도 반영됩니다.
- **고르는 칸**: 자료 종류, 자기평가, 교사 기준표는 드롭다운 대신 눌러서 고르는 버튼입니다. 같은 버튼을 다시 누르면 선택이 풀립니다.

## 운영

- **둘러보기.** 학생은 로그인 없이 다섯 단계, 안내, 예시를 모두 볼 수 있습니다. 칸에 써 볼 수는 있지만 저장되지 않습니다.
- **명단으로 제한하기(권장).** `명단` 시트 A열 학번, B열 이름, C열 생년월일(월일 4자리)을 적어 두면 명단에 있는 학생만 들어올 수 있습니다.
  - C열이 있으면 **처음 비밀번호는 생년월일 4자리**입니다(예: 3월 10일 → 0310). 시트가 310처럼 앞의 0을 지워도 0310으로 맞춰 보고, 학생이 310으로 써도 들어옵니다. 20080310·080310처럼 써도 월일만 봅니다.
  - 생년월일이 있는 학생은 다른 비밀번호로 처음 가입할 수 없어, 친구가 먼저 가입해 버리는 일을 막습니다. 비밀번호를 초기화한 뒤에도 생년월일로만 다시 들어옵니다.
  - 생년월일은 친구가 알 수도 있으므로, 처음 들어오면 '🔑 비밀번호 바꾸기'를 권하는 안내가 나옵니다(생년월일로는 바꿀 수 없음).
  - C열이 비어 있는 학생은 예전처럼 처음 들어올 때 스스로 비밀번호를 정합니다.
- **학생 비밀번호.** 학생이 처음 들어올 때 스스로 정합니다. 10번 연속 틀리면 5분 동안 잠기고(교사 현황표에 🔒 표시), 교사 화면의 '학생 비밀번호 초기화'로 바로 풀 수 있습니다.
- **저장.** 학생이 글을 고치고 1분 동안 멈추면 자동 저장되고, **저장하기**를 누르거나 다른 단계로 넘어갈 때도 저장됩니다. 인터넷이 끊겨 저장하지 못하면 그 기기에 보관했다가 연결되면 저절로 보냅니다(다음에 같은 기기로 로그인해도 보냅니다). 저장 전에 창이 닫혀도 같은 기기에서 3일 안에는 다시 불러옵니다. '나가기'를 누르면 그 기기에 남은 글을 지웁니다(공용 컴퓨터 대비).
- **학생에게 보이는 것.** 확인 ①②③과 선생님 한마디만 보입니다. 기준표, 관찰 메모, 특기사항 초안은 보이지 않습니다.
- **특기사항 초안.** 학생 상세에서 쓰고, 글자 수(진로활동 특기사항 전체 500자 기준)를 보여 줍니다. '📚 완성 예시' 탭에 예시 학생 2명의 보고서와 평가 기록, 특기사항 작성 해설이 있습니다.
- **백업·초기화(⚙️ 관리 탭).** '지금 백업 시트 만들기'는 `보고서` 시트를 `백업 날짜 시각` 시트로 복사합니다. '백업하고 초기화'는 고른 반이나 모든 학생의 줄을 지우기 직전에 백업 시트를 자동으로 만듭니다. 되돌리려면 백업 시트의 학생 줄을 `보고서`로 복사해 넣습니다.
- **인쇄.** 쪽마다 위에 보고서 이름과 학생(또는 반), 아래에 출력 일시와 쪽수가 들어갑니다. 크롬·엣지 최신 버전에서 나오고, 인쇄 창의 '머리글과 바닥글'은 끄면 깔끔합니다. 아이폰·아이패드 사파리는 쪽수 머리말을 지원하지 않아 첫 쪽 표의 '출력 일시'만 나옵니다.

## 칸·예시를 바꾸고 싶을 때

1. `js/schema.js`를 고칩니다. 새 칸은 새 `key`(영문 소문자·숫자)로 더하고, 이미 쓰는 `key`는 바꾸지 않습니다(시트 열 이름).
2. 칸을 더하거나 뺐다면 `node tools/build-code-gs.js`로 `apps-script/Code.gs`를 다시 만들고 `node tools/test-code-gs.js`로 시험합니다. 시트에 새 열은 학생이 저장할 때 자동으로 생기므로, 예시 문구만 고쳤다면 이 단계는 필요 없습니다.
3. `index.html`의 `?v=5` 숫자를 올리면 학생 브라우저가 새 파일을 바로 받습니다.

## 보안

| 항목 | 내용 |
| --- | --- |
| 교사 비밀번호 | 코드가 아니라 Apps Script 스크립트 속성에 둠(10자 이상). 10분 안에 8번 틀리면 10분 차단(맞게 들어오면 횟수 초기화), 차단 중에도 보조 비밀번호 `TEACHER_PASSWORD2`로는 들어옴, 비교 시간도 일정하게 |
| 교사 화면 | 30분 동안 쓰지 않으면 자동 로그아웃, '로그아웃' 버튼, 비밀번호는 브라우저에 저장하지 않음 |
| 학생 비밀번호 | 학번과 섞어 SHA-256으로 저장, 10번 틀리면 5분 잠금, 잠긴 학생은 교사 현황표에 🔒 |
| 학생이 쓸 수 있는 칸 | 정해진 이름 규칙의 칸만, 칸당 3,000자. 교사 칸(`t_`)·저장 시각·학번은 바꿀 수 없음 |
| 시트 수식 공격 | `=`, `+`, `-`, `@`로 시작하는 글은 글자로만 저장 |
| 장난 등록 | `명단` 시트 권장(비어 있으면 교사 화면에 경고), 명단 없이도 최대 1,500명 |
| 화면 공격(XSS) | 학생 글을 HTML로 해석하지 않고 글자로만 표시. CSP로 이 사이트 밖 스크립트·폼 전송·플러그인 차단 |
| 초기화 | '초기화' 글자 확인 + 확인 창 + 자동 백업 |

남는 한계도 있습니다. GitHub Pages는 응답 헤더를 바꿀 수 없어 다른 사이트가 이 페이지를 틀(iframe) 안에 넣는 것까지는 막지 못합니다. 교사 화면은 비밀번호로만 보호하므로 비밀번호를 학생 앞에서 입력하지 마세요.

## 교사 화면 사용 팁

- 반 고르기 목록에 반별 인원이 나옵니다. 학생이 120명을 넘으면 처음에는 한 반만 불러오고, 반을 바꿀 때마다 그 반을 불러옵니다(느려지지 않게).
- '확인 안 한 학생만'을 켜면 저장했지만 선생님 확인이 아직인 학생만 보입니다.
- 선택·도전 칸(🚀)은 학생 화면에서 접혀 있고, 누르면 펼쳐집니다. 쓴 내용이 있으면 펼쳐진 채로 보입니다.

## 개인정보

시트에는 학번, 이름, 학생이 쓴 글이 저장됩니다. 학교의 개인정보 처리 방침과 학생·보호자 안내 필요 여부를 확인해 주세요. 활동이 끝나면 내려받아 보관하거나 '백업하고 초기화'로 정리합니다.
