# 진로 빌드업 맵 탐구 보고서 — 온라인 제출 도구

학생은 웹페이지에서 5단계(1차시 → 과제 1 → 2차시 → 과제 2 → 3차시)로 보고서를 저장하고, 내용은 선생님의 구글 시트에 쌓입니다. 선생님은 같은 페이지의 교사 화면에서 제출 현황, 확인·피드백, 평가 기준표, 학생부 작성용 요약을 봅니다.

## 바로 가기

- **학생용**: <https://2023swhs3rd-a11y.github.io/report/>
- **선생님용**: <https://2023swhs3rd-a11y.github.io/report/#teacher> (교사 비밀번호 필요)
- 진로진학부 사이트 첫 화면: <https://2023swhs3rd-a11y.github.io/>

## 파일

| 파일 | 용도 | 올리는 곳 |
| --- | --- | --- |
| `index.html` | 학생 화면 + 교사 화면 | GitHub 저장소 |
| `img/map.svg`, `img/done.svg` | 첫 화면 탐구 지도 그림, 다섯 단계 완성 그림 | GitHub 저장소 |
| `Code.gs` | 구글 시트에 저장하는 스크립트 | 구글 시트의 Apps Script (GitHub에 올리지 않음) |
| `README.md` | 이 안내서 | 선택 |

`index.html`의 `API_URL`이 비어 있으면 **미리보기 모드**로 열립니다. 파일을 더블클릭해서 화면을 먼저 살펴볼 수 있습니다(교사 비밀번호 `demo`, 그 기기에만 저장).

## 설치 (약 15분)

### 1. 구글 시트와 스크립트

1. 구글 드라이브에서 새 스프레드시트를 만듭니다. 이름 예: `2026 빌드업맵 탐구 보고서`. **다른 사람과 공유하지 않습니다.**
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 들어 있는 코드를 모두 지우고 `Code.gs` 내용 전체를 붙여 넣습니다.
4. 맨 위의 `TEACHER_PASSWORD`를 8자 이상의 비밀번호로 바꿉니다.
5. 위쪽 함수 목록에서 `setup`을 고르고 **실행**을 누릅니다. 처음에는 권한 승인 창이 뜹니다. 본인 계정으로 승인합니다.
6. 시트로 돌아가면 `보고서`, `명단` 시트가 생겨 있습니다.

### 2. 웹 앱으로 배포

1. Apps Script 오른쪽 위 **배포 → 새 배포**.
2. 유형: **웹 앱**. 실행 계정: **나**. 액세스 권한: **모든 사용자**.
3. **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
4. 이 주소를 브라우저에 붙여 넣어 `저장 서버가 동작 중입니다`가 보이면 정상입니다.

학교 구글 계정에서 '모든 사용자' 선택지가 보이지 않으면 관리자가 외부 공개를 막아 둔 것입니다. 그때는 관리자에게 요청하거나 다른 방법을 정해야 하니 알려 주세요.

### 3. 웹페이지 올리기

1. `index.html`을 메모장으로 열어 위쪽 `const API_URL = "";`의 따옴표 안에 복사한 주소를 붙여 넣고 저장합니다.
2. GitHub `2023swhs3rd-a11y` 계정에 새 공개 저장소를 만듭니다. 이름: `report` (만들어 둠).
3. `index.html`을 올립니다. **비밀번호를 바꾼 `Code.gs`는 올리지 않습니다.**
4. 저장소 **Settings → Pages → Deploy from a branch → main / (root)** 로 저장합니다.
5. 1~2분 뒤 주소가 열립니다.
   - 학생용: `https://2023swhs3rd-a11y.github.io/report/`
   - 교사용: `https://2023swhs3rd-a11y.github.io/report/#teacher`

### 4. 수업 전 점검

- 학생 화면에서 연습용 학번(예: 19999)으로 들어가 1차시를 저장하고, 시트 `보고서`에 줄이 생겼는지 확인합니다.
- 교사 화면에서 그 학생이 보이는지, 확인 ①을 저장하면 학생 화면에 나타나는지 확인합니다.
- 확인이 끝나면 시트에서 연습용 줄을 지웁니다.

## 운영

- **명단으로 제한하기(권장).** `명단` 시트에 학번과 이름을 적어 두면 명단에 있는 학생만 들어올 수 있습니다. 비워 두면 주소를 아는 누구나 아무 학번으로 등록할 수 있습니다.
- **학생 비밀번호.** 학생이 처음 들어올 때 스스로 정합니다. 잊어버리면 교사 화면에서 학생을 누르고 **학생 비밀번호 초기화**를 누릅니다. 다음 접속 때 새로 정합니다. 10번 연속 틀리면 잠기며, 초기화하면 풀립니다.
- **저장.** 학생은 단계마다 **저장하기**를 누릅니다. 다른 단계로 넘어갈 때는 자동으로 저장됩니다. 저장 전에 창이 닫혀도 같은 기기에서는 쓰던 내용을 다시 불러옵니다.
- **현황표의 표시.** ● 완료(저장했고 필수 칸을 모두 채움), ◐ 작성 중, ○ 아직.
- **학생에게 보이는 것.** 확인 ①②③과 한마디만 보입니다. 평가 기준표와 관찰 메모는 보이지 않습니다.
- **학생부 작성용 요약.** 질문·근거·달라진 생각·다음 질문 등 학생이 쓴 칸만 모아 보여 줍니다. 문장을 자동으로 만들지 않습니다. **표로 복사**를 누르면 엑셀이나 한글 표에 붙여 넣을 수 있습니다.
- **스크립트를 고쳤을 때.** Apps Script에서 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. 주소는 그대로입니다.

## 칸을 바꾸고 싶을 때

`index.html` 위쪽의 `STAGES` 부분만 고치면 됩니다. 새 칸을 추가하면(`key`는 영문 소문자·숫자) 시트에 열이 자동으로 생깁니다. 이미 쓰는 `key`의 이름은 바꾸지 않는 것이 안전합니다.

## 개인정보와 한계

- 시트에는 학번, 이름, 학생이 쓴 글이 저장됩니다. 학교의 개인정보 처리 방침에 맞는지, 학생·보호자 안내가 필요한지 확인해 주세요. 시트는 공유하지 말고, 활동이 끝나면 내려받아 보관하거나 삭제합니다.
- 학번 + 이름 + 스스로 정한 비밀번호는 가벼운 보호 장치입니다. 비밀번호는 암호화해 저장하지만, 성적처럼 민감한 정보를 다루는 수준의 보안은 아닙니다.
- 한 반이 같은 순간에 한꺼번에 저장하면 몇 초씩 기다릴 수 있고, 드물게 "접속이 많습니다"가 뜰 수 있습니다. 쓰던 내용은 화면에 남아 있으니 다시 **저장하기**를 누르면 됩니다.
- 저장 스크립트는 모의 시트로, 웹페이지는 미리보기 모드로 점검했습니다. 실제 구글 계정에 배포한 상태의 점검은 위 '수업 전 점검'으로 해 주세요.
